# 阶段 2 方法论总结 —— 三大数学工具,以及本项目为什么选它们

> 本文把阶段 2 学到的全部知识点,连同「**本项目为什么这么选**」的理由,整理成可独立查阅的参考。
> 一句话主线:**SVD 回答「表征摊成了什么形状」,SVM 回答「这个形状是不是真按语义组织的」,两者合起来才是完整的几何画像;而预处理保证这场对比绝对公平。**

---

## 0. 总览:为什么需要这一整套

线性探针**准确率**是个单一数字,它把丰富的几何压成一个标量——只能答「学没学到」,答不了「学成了什么形状、有多稳健」。**两个准确率相同的模型,内部几何可以天差地别。**

所以本项目用一套**几何工具**去看准确率看不见的东西。但单一几何指标(比如有效秩)**本身有歧义**:

| | 秩高 | 秩低 |
|---|---|---|
| **可能是好** | 特征丰富 | 组织干净、可分 |
| **可能是坏** | 只是噪声铺得开 | 维度坍缩,信息全丢 |

光看「秩」这个数字,这四格分不清自己在哪格。**这就是为什么必须 SVD + SVM 配合**:SVD 给嫌疑,SVM 定罪。

## 1. SVD 谱分析 与 RankMe 有效秩

### 1.1 视角切换:Z 不是「映射」,是「点云」
本项目里 SVD 的对象是**特征矩阵** $Z \in \mathbb{R}^{N\times d}$ —— **N 个数据点 × d 维特征**(如 STL-10 测试集 = 8000 点飘在 384 维)。
- **右奇异向量 V** = 点云的主轴方向
- **奇异值 $\sigma_k$** = 点云沿第 k 根主轴**摊得有多开**(方差)
  - $\sigma_k$ 大 = 该方向方差大、承载结构;$\sigma_k$ 小 = 该方向又扁又薄。

### 1.2 与 PCA 的关系(以及为什么去均值)
把 $Z$ **去均值**后再 SVD,**就等价于 PCA**,奇异值平方 ∝ 沿各主成分的方差。
→ **设计决策:SVD 前必须 mean-center**,让谱反映「方差结构」而非被数据整体偏移污染。
代码:[`src/analysis/svd.py`](../src/analysis/svd.py) `svd_spectrum(center=True)`。

### 1.3 怎么把谱概括成「有效维度个数」
- **朴素办法 top-p / 累计方差阈值**:数「覆盖 90%/99% 方差需要几个奇异值」。
  代码里就是 `n_dims_for_90pct` / `n_dims_for_99pct`。
  **软肋**:阈值主观;且「一刀切」是二值的——对奇异值的大小和长尾形状是瞎的,说不出「算 0.5 个维度」。
- **RankMe(本项目主指标,Garrido et al. 2023)**:用**熵**解决上述软肋。

### 1.4 RankMe 公式与直觉
把奇异值归一成概率分布 $p_k = \sigma_k / \sum_j \sigma_j$,则

$$\boxed{\ \text{RankMe} = \exp\!\Big(-\sum_k p_k \log p_k\Big)\ }$$

- **熵**衡量这个分布「多均匀」:全均匀→最大,全压一项→0。
- **exp** 把熵(单位 nats)翻译回「有效维度个数」(perplexity)。
- 两个边界印证设计:
  - 滚圆的球(d 个 σ 相等):$p_k=1/d$,熵 $=\log d$,RankMe $= d$(满维,高有效秩)
  - 塌成一条线(一个 σ 独大):熵 $\to 0$,RankMe $= 1$(维度坍缩,低有效秩)
- 工程细节:`rankme_epsilon` 给 $\log$ 兜底防 NaN。代码 [`svd.py: rankme()`](../src/analysis/svd.py)。

**RankMe 满足的「心愿清单」**:① 不用人为阈值 ② 用上全部 σ ③ 按相对大小平滑加权 ④ 能给小数。

### 1.5 ⚠️ 重要立场:有效秩是「描述符」,不是「质量分」
高秩不一定好(可能只是噪声);低秩不一定坏(可能干净可分)。**RankMe 只刻画几何,不给 encoder 排座次。**

### 1.6 本项目为什么用它
- 用一个**无标签、任务无关**的数字刻画表征几何 —— 这正是 RankMe 被提出的动机(可在不做完整下游评估的情况下预判表征值不值得 scale)。
- 它是 MAE vs I-JEPA **同架构对照**的主战场指标。

## 2. Two-NN 本征维数(SVD 的非线性补充)

### 2.1 它补的洞:SVD 是「直」工具
SVD/RankMe 只会用**笔直的主轴**套点云,遇到**弯曲流形会高估维度**。
- 例:螺旋曲线本征 = **1 维**(一个角度 θ 就定位),但在直角坐标里铺满平面,SVD 误判为 2 维。
- **本征维数 = 确定流形上一点所需的「自由旋钮数」(degrees of freedom)**,与它在几维空间里如何弯曲无关。

### 2.2 核心招式:局部可线性化(微分几何的切空间)
光滑流形**局部都近似平直**(地球局部看着平)。**弯曲是全局性质,凑得够近就消失** → 只看每个点的**近邻**,就能量到「真实的局部自由度」,绕开弯曲。

### 2.3 机制三步(Facco et al. 2017)
1. **局部测量用比值**:每点取到第 1、第 2 近邻的距离 $r_1, r_2$,只取 $\mu = r_2/r_1 \ (\geq 1)$。
   **为什么用比值**:比值**消掉局部密度差异**,让稠密区和稀疏区的测量变得可比、可汇总。(因此不要求全局均匀。)
2. **分布里藏着 d**:$d$ 维球体积 ∝ $r^d$ → 体积比 $=\mu^d$;由泊松采样性质,$\mu \sim \text{Pareto}(d)$,即 $F(\mu)=1-\mu^{-d}$。
3. **局部 → 整体**:对 $F$ 取对数得 $-\log(1-F(\mu)) = d\cdot\log\mu$。把**全体点**的 $\mu$ 汇成经验 CDF,做**过原点直线拟合**,斜率即单一全局 $d$。
   → **不是平均一堆噪声维度,而是从汇总分布里抠出共享的指数 $d$。**
   代码:[`src/analysis/intrinsic_dim.py`](../src/analysis/intrinsic_dim.py),`d=(x·y)/(x·x)`;`discard_fraction` 砍掉重尾里不守规矩的 10%。

### 2.4 与 RankMe 的「互补」关系
- Two-NN ≈ RankMe → 流形基本是**平的**,线性近似够用。
- Two-NN ≪ RankMe → 流形**弯得厉害**,SVD 高估了。
- 代码量化二者之差:`curvature_gap_rankme_minus_twonn`。

### 2.5 本项目为什么用它
单靠 SVD(线性)会被曲率欺骗;Two-NN 提供**非线性的本征维数**,两者并看才能判断「这张流形到底是平的子空间,还是真有曲率」。

## 3. SVM 线性探针(把「无人区有多宽」变成数字)

### 3.1 间隔公式
分界超平面 $w^\top x + b = 0$,两侧护栏钉在 $\pm 1$,则

$$\text{margin} = \frac{2}{\lVert w\rVert}$$

护栏位置固定,**要让无人区更宽,只能让 $\lVert w\rVert$ 更小** → 目标函数:

$$\min_{w,b}\ \tfrac12\lVert w\rVert^2 + C\sum_i \xi_i,\quad \text{s.t. } y_i(w^\top\phi(x_i)+b)\ge 1-\xi_i$$

- $\tfrac12\lVert w\rVert^2$:最大化间隔。
- $C\sum\xi_i$:惩罚越界/分错($\xi_i$ = 越界量)。现实类别有重叠,允许少数越界但要罚。
- **$C$**:间隔宽 ↔ 容忍越界 的权衡。大 = 硬(易过拟合),小 = 软。代码默认 `svm.C=1.0`。

### 3.2 三个诊断量(都比准确率信息更丰富)
- **间隔(margin)**:越宽 = 类别越线性可分、组织越干净。
- **支持向量数**:压在护栏上/越界的点,**唯一决定**边界位置;越少 = 决策面越干净。代码 `n_support_vectors` / `support_vector_fraction`。
- **混淆矩阵 / 最难分类对**:哪些类最难分,是否对应语义相似。代码 `hardest_pairs`。
代码:[`src/analysis/svm_probe.py`](../src/analysis/svm_probe.py)。

### 3.3 本项目为什么用它
准确率只答「分不分得开」,**间隔/支持向量答「分得多干净、多稳健」**。这正是「定罪」工具——它能拆穿「高秩但语义糊」的坏高秩。

## 4. 连接 SVD ↔ SVM(项目核心贡献)与因果诚实底线

### 4.1 判决表(高潮)
| | RankMe(嫌疑) | SVM 间隔(定罪) | 判决 |
|---|---|---|---|
| **MAE** | 高(像素辞藻撑高熵) | **窄** | **坏高秩**:方差多,但不按语义组织 |
| **I-JEPA** | 可能更低 | **宽** | 好结构:方差少而精,按语义排布 |

**「高秩 + 窄间隔」= 坏高秩铁证;「(不一定高的)秩 + 宽间隔」= 好结构。**
代码:[`src/analysis/connect.py`](../src/analysis/connect.py) 汇总各 encoder 的 rank 与 margin。

### 4.2 ⚠️ 只能说相关,不能说因果
1. **样本太少**:全程才 3–4 个 encoder,4 个点穿一条线是「趣闻」不是「规律」。代码算 Pearson/Spearman 但标注 *descriptive*。
2. **可能有共因**:秩与间隔之间也许没有直接箭头,而是**同被「训练目标」这一上游同时推动**:

```
                ┌──→ 高有效秩
   训练目标 ────┤
                └──→ 宽间隔
```

### 4.3 MAE/I-JEPA 对照控住了什么、没控住什么
- 同 ViT 骨架(默认 ViT-L/16) → **排除「架构」混淆** → 可归因「**训练目标 → 几何差异**」。
- **但仍不能**说「**有效秩 → 高可分性**」:那条箭头未被建立,秩与间隔仍可能只是共因的下游。
- 最终判词永远是:**structural correlation, not a causal claim**(写死在 `connect_report.json` 的 note)。

## 5. 预处理三步 —— 把四个 encoder 摆上公平擂台

| 步骤 | 堵住的「作弊漏洞」 | 关键理由 |
|---|---|---|
| **随机投影 → 384** | 维度不同导致几何不可比(维度灾难) | ResNet 512-d vs ViT-L 1024-d;统一到 384 才可比 |
| **L2 归一化** | 模长尺度不同导致不可比 | 压到单位球面,比「方向(夹角)」 |
| **去均值** | 整体偏移污染方差谱 | 让 SVD = PCA,谱反映结构本身 |

### 5.1 随机投影:怎么做 + 为什么是「随机」
- **怎么做**:固定矩阵 $R\in\mathbb{R}^{d_{in}\times 384}$,元素 $\overset{iid}{\sim}\mathcal{N}(0, 1/384)$;投影 = $xR$。
  方差取 $1/384$ 使 $\mathbb{E}\lVert xR\rVert^2 = \lVert x\rVert^2$(长度期望不变)。**种子固定 42**,保证可复现、train/test 用同一个 $R$。
- **为什么保结构**:**Johnson–Lindenstrauss 引理** —— 随机线性投影以极高概率近似保住点对距离(测度集中;呼应「高维高斯/醉汉走路」)。
- **为什么不用 PCA**(关键):
  - **循环论证**:PCA 按每个 encoder 自己的**方差谱**挑方向,而我们要量的 RankMe **恰恰就是方差谱的熵**——用要量的东西去预处理,量尺先动了手脚。
  - **不公平**:PCA 给每个 encoder 各拟合一把「量身定做的尺」;随机矩阵**不看数据、对所有 encoder 用同一把中立尺**。
- 代码:[`src/features/preprocessing.py`](../src/features/preprocessing.py) `RandomProjection`。

### 5.2 总纲
**预处理 = 确保最终量出的几何差异,只可能来自「表征本身」,不来自尺度 / 维度 / 偏移这些场外因素。**

## 6. 一页速查

| 工具 | 测什么 | 公式核心 | 本项目为什么要它 |
|---|---|---|---|
| **RankMe** | 线性有效秩(几何描述符) | $\exp(\text{熵}(p_k))$ | 无标签刻画几何;MAE/I-JEPA 主指标 |
| **Two-NN** | 非线性本征维数 | $\mu=r_2/r_1$,CDF 拟合斜率 | 补 SVD 看不见的曲率 |
| **SVM 间隔** | 线性可分性/稳健性 | $2/\lVert w\rVert$ | 拆穿坏高秩(定罪) |
| **连接分析** | 秩↔间隔的结构关联 | 跨 encoder 对照 | 核心贡献;严守「相关≠因果」 |
| **预处理** | 公平性保障 | 随机投影+L2+去均值 | 排除尺度/维度/偏移的场外混淆 |

> 记忆锚点:**SVD 给嫌疑,SVM 定罪;Two-NN 看流形弯不弯;预处理保证审判公平。**
